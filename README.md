# OPEN 无界社交平台

开放、自由、连接世界的综合社交平台。

## 技术栈

- **前端**: Next.js 16 + React 19 + TypeScript
- **样式**: Tailwind CSS 4
- **状态管理**: Zustand
- **图标**: Lucide React
- **头像**: DiceBear API

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 启动生产服务器
npm start
```

访问 http://localhost:3000

## 项目结构

```
src/
├── app/                    # Next.js App Router 页面
│   ├── page.tsx           # 首页（重定向到 /world）
│   ├── layout.tsx         # 根布局
│   ├── globals.css        # 全局样式
│   ├── world/             # 世界聊天大厅
│   ├── nearby/            # 地方区域聊天
│   ├── friends/           # 好友与发现
│   ├── moments/           # 动态广场
│   ├── profile/           # 个人主页
│   └── chat/[id]/         # 聊天界面（群聊/私聊）
── components/
│   ├── layout/            # 布局组件（顶部栏、底部导航）
│   ├── chat/              # 聊天组件
│   ├── world/             # 世界聊天组件
│   ├── friends/           # 好友组件
│   ├── moments/           # 动态组件
│   ├── profile/           # 个人主页组件
│   └── common/            # 通用组件（头像、用户卡片）
├── store/                 # Zustand 状态管理
├── data/                  # 模拟数据
└── types/                 # TypeScript 类型定义
```

## 功能模块

### 1. 世界聊天大厅 (`/world`)
- 全球公开聊天室列表
- 按分类筛选（科技、音乐、旅行、美食等）
- 搜索聊天室
- 收藏/加入聊天室
- 点击进入聊天

### 2. 地方区域 (`/nearby`)
- 按国家/城市分类
- 热门话题展示
- 城市聊天室
- 活跃用户展示
- 区域推荐

### 3. 好友系统 (`/friends`)
- 好友列表（在线状态）
- 好友申请处理（接受/拒绝）
- 用户发现与推荐
- 群组管理
- 搜索好友

### 4. 动态广场 (`/moments`)
- 推荐流/关注流
- 发布动态（文字+图片）
- 点赞、评论、分享、收藏
- 话题标签
- 可见性设置

### 5. 个人主页 (`/profile`)
- 自定义头像、封面、简介
- 动态/相册/资料切换
- 好友/关注/粉丝统计
- 编辑模式
- 设置面板（隐私、通知、深色模式）

### 6. 聊天界面 (`/chat/[id]`)
- 群聊和私聊统一界面
- 实时消息发送
- 表情选择
- 自动回复（模拟）
- 成员信息面板
- 语音/视频通话按钮（预留）
